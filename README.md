##  О проекте

LMS Project - это бэкенд-сервер для онлайн-платформы обучения, разработанный на Django REST Framework. Проект предоставляет API для управления курсами, уроками, пользователями, платежами и подписками с гибкой системой прав доступа.

##  Функционал

### Базовый функционал
-  Регистрация и JWT-авторизация пользователей
-  CRUD операции для курсов и уроков
-  Разграничение прав доступа (модераторы, владельцы)
-  Пагинация списков курсов и уроков
-  Валидация YouTube ссылок в уроках
-  API документация (Swagger/ReDoc)

### Новый функционал

#### 1. Интеграция с Stripe 
- **Создание продуктов в Stripe**: автоматическое создание продукта при создании платежа
- **Динамические цены**: создание цены в Stripe на основе суммы платежа
- **Платежные сессии**: генерация ссылок на оплату через Stripe Checkout
- **Проверка статуса платежа**: эндпоинт для проверки статуса оплаты
- **Поддержка тестовых карт**: возможность тестирования платежей без реальных денег

#### 2. Система подписок на курсы 
- **Подписка на обновления**: пользователи могут подписываться на курсы
- **Управление подписками**: добавление и удаление подписок через единый эндпоинт
- **Визуализация статуса**: поле `is_subscribed` в сериализаторе курса
- **Защита от дублирования**: уникальная пара (пользователь, курс)

#### 3. Расширенная система платежей 
- **Гибкая фильтрация**: фильтрация платежей по курсу, уроку и способу оплаты
- **Сортировка по дате**: возможность сортировки платежей по дате оплаты
- **Привязка к пользователю**: каждый платеж привязан к конкретному пользователю
- **Поддержка Stripe**: интеграция с платежной системой Stripe

#### 4. Улучшенная документация API 
- **Swagger UI**: интерактивная документация с возможностью тестирования эндпоинтов
- **ReDoc**: альтернативный формат документации
- **OpenAPI Schema**: автоматическая генерация OpenAPI спецификации

#### 5. Тестовое покрытие 
- **Unit-тесты**: полное покрытие CRUD операций
- **Тесты прав доступа**: проверка работы модераторов и владельцев
- **Тесты подписок**: проверка добавления и удаления подписок
- **Тесты платежей**: проверка фильтрации, сортировки и Stripe интеграции
- **Тесты авторизации**: проверка JWT токенов и регистрации

## 🛠 Технологии

- **Django 4.2** - веб-фреймворк
- **Django REST Framework 3.14** - создание API
- **JWT (Simple JWT)** - авторизация
- **Stripe API 7.5.0** - платежная система
- **drf-spectacular 0.26.2** - документация API
- **django-filter 23.5** - фильтрация данных
- **SQLite** - база данных (разработка)
